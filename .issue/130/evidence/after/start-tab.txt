## 3. SKILL.md 재전송 절차 실측 (오케스트레이터가 만든 테스트 폴더)
send-keys down → ❯ Yes, I trust this folder → enter
agent wait --until idle                          → rc=0
agent prompt "<프롬프트>" --wait --until working  → 실패(입력창에 글자만 남고 제출 안 됨) — 스크립트였다면 NOT_STARTED:idle, exit 3
send-keys enter → agent wait --until working    → working, 응답 "● OK"
