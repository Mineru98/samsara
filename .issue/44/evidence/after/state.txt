### 8. `issue-version` — 결계 각인 (結界刻印)

> **[설화]** 인들이 하나씩 잠들어 명부에 쌓이면, 술자는 그 무덤 전체에 하나의 이름을 새깁니다. 이름 없는 결계는 어느 시점의 것인지 아무도 되짚지 못하고, 각인이 서로 어긋난 결계는 다음 술자가 발을 들이는 순간 무너집니다. 여덟 개의 석판에 같은 이름을 동시에 새기고, 지난 각인 이후 잠든 인들을 모두 헤아려 비문으로 남깁니다.
>
> **[술식]** `major`·`minor`·`patch` 중 하나를 받아 현재 버전을 판정하고 한 단계 올립니다. 버전이 박힌 8개 파일을 함께 갱신한 bump PR 을 만들고 거기서 멈추며, 그 PR 이 merge 된 뒤 다시 부르면 태그를 달고 직전 태그 이후의 커밋을 type 별로 묶은 릴리즈를 발행합니다. 태그가 하나도 없으면 `v0.1.0` 에서 시작합니다.

```bash
/issue-version patch     # v0.3.2 → v0.3.3   버그 수정·문서 정리
/issue-version minor     # v0.3.2 → v0.4.0   기능 추가
/issue-version major     # v0.3.2 → v1.0.0   호환성이 깨지는 변경
```

한 번 부르면 절반만 갑니다. **1단계는 `release/vX.Y.Z` 브랜치에 8개 파일을 올린 bump PR 을 만들고 거기서 멈춥니다.** 그 PR 을 사람이 검토해 merge 한 뒤 같은 명령을 다시 부르면, 2단계로 태그를 달고 릴리즈를 냅니다.

이름을 새기는 일을 술식 혼자 끝내지 않는 이유는 하나입니다. 각인은 되돌리기 가장 어려운 술법이고, 되돌릴 수 없는 것 앞에는 반드시 사람이 서야 하기 때문입니다.
