### 증거 생략 사유

문서(`skills/issue-create/references/issue-draft.md`) 한 파일만 바뀌어 화면 캡처·측정 대상이 없다. 아래 변경 근거로 대신한다.

### 변경 내용

- 기본 틀의 `## 참고` 앞에 `## 선행 이슈` / `## 후행 이슈` 추가. 두 섹션 모두 완료 기준과 같은 체크박스 항목 `- [ ] [#<번호>](<이슈 URL>) <제목>`
- `## 선행 · 후행 이슈` 작성 가이드 추가
  - 항목마다 이슈 링크 필수, 번호만 쓰지 않음
  - 주소는 `gh issue view <번호> --json url,title` 로 받아 씀
  - 연결은 양쪽 본문에 남김
  - `[ ]` 아직 안 끝남 / `[x]` 닫힘(merge 완료), 이 버전은 작성자가 손으로 갱신
  - 연결이 없으면 `없음`
