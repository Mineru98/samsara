## 작업 요약

issue-* 스킬이 GitHub 에 남기는 본문(이슈·코멘트·PR·릴리즈 노트)에서 Claude Code attribution 푸터와 세션 링크를 금지했습니다.
가이드에 규칙을 넣고, 런타임 지시를 따라 다시 붙는 경우에 대비해 스크립트에서도 걸러냅니다.

```text
🤖 Generated with [Claude Code](https://claude.com/claude-code)
https://claude.ai/code/session_<id>
_Generated by [Claude Code](https://claude.ai/code/session_<id>)_
```

## 변경 전후

화면 변경이 없는 작업(문서 + 스크립트 텍스트 처리)이라 캡처 대신 같은 입력으로 돌린 출력을 남겼습니다. 입력은 위 세 형태와 코드 펜스 안의 예시 한 줄을 함께 넣은 본문입니다.

| 항목 | 전 | 후 |
| --- | --- | --- |
| `issue-create create --dry-run` | 푸터를 그대로 등록 | 3줄 제거 예정 출력, `ATTRIBUTION_REMOVED=3` (펜스 안 예시는 유지) |
| `report-check` (validateEvidenceReport) | `ok: true` 로 통과 | `ok: false`, 3건 차단 (exit 5) |
| 가이드 9개 파일의 금지 규칙 | 0건 | 9개 파일 모두 반영 |

원본: [before/attribution-probe.txt](https://github.com/Mineru98/samsara/blob/dev/0.4.0-alpha/.issue/106/evidence/before/attribution-probe.txt) · [after/attribution-probe.txt](https://github.com/Mineru98/samsara/blob/dev/0.4.0-alpha/.issue/106/evidence/after/attribution-probe.txt)
