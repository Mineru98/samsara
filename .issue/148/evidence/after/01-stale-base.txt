## 1. 문서의 기준 변경 명령
$ node issue-start.mjs base --set main
BASE=main
SOURCE=project
DETECTED_AT=2026-11-07T04:41:04.624Z
(exit 0)

## 2. 낡은 기준(dev/0.4.0-alpha)에서 워크트리 생성
$ node issue-start.mjs worktree 129 --slug herdr-tab --no-status
  브랜치 : fix/129-herdr-tab (신규, origin/dev/0.4.0-alpha 기준)
  워크트리: <tmp>/repo-issue-129
✗ 기준 브랜치 origin/dev/0.4.0-alpha 에 이슈 #129 의 영향 경로가 없습니다. 워크트리를 만들지 않았습니다.
    - skills/herdr-orch/SKILL.md
  기준 출처: .issue/settings.json git.baseBranch (기록 시각 2026-09-28T00:00:00.000Z)
  위 경로는 origin/main 에는 있습니다.
  기준 고정: base --set <branch> / 이번만: --base <branch> / 이 기준이 맞으면: --allow-missing-paths
BASE_PATHS_MISSING=skills/herdr-orch/SKILL.md
BASE=dev/0.4.0-alpha
BASE_CANDIDATE=main
(exit 5)

  결과: 워크트리 없음, 그 안의 skills/herdr-orch 없음

## 3. 기준을 main 으로 고친 뒤 워크트리 생성
$ node issue-start.mjs worktree 129 --slug herdr-tab --no-status
  브랜치 : fix/129-herdr-tab (신규, origin/main 기준)
  워크트리: <tmp>/repo-issue-129

✓ 워크트리 준비 완료
  .issue/129/ 를 워크트리로 복사했다 (1개 항목)
WORKTREE_PATH=<tmp>/repo-issue-129
WORKTREE_DISPLAY=<tmp>/repo-issue-129
BRANCH=fix/129-herdr-tab
(exit 0)

  결과: 워크트리 생성됨, 그 안의 skills/herdr-orch 있음
